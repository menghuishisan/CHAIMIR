# 评测引擎 权限矩阵

> 最后更新:2026-08-25

本模块无独立于身份(identity)模块的用户权限扩展。所有用户角色、数据范围与操作权限继承 `docs/01-身份与租户/04-权限矩阵.md` 的租户 RBAC 定义;本模块接口仅按角色开放对应操作,不新增用户角色或数据范围维度。

| 角色 | 本模块数据范围 | 本模块操作权限 |
| --- | --- | --- |
| 学生(student) | 本人提交的作答与判题结果 | 触发本人判题、查看本人成绩 |
| 教师(teacher) | 本人创建/任教的题目与判题配置 | 配置判题器、查看任教范围判题结果 |
| 校管(school_admin) | 本校租户内全部判题记录 | 本校判题审计与策略管理 |
| 平台管理员(platform_admin) | 跨租户(平台维度) | 平台级判题治理 |

> 引擎内部的判题调度 worker、judge 沙箱执行器等自动化组件以平台服务身份运行,不属于上述用户角色,其权限由架构设计与 `06-安全设计.md` 约束,不在此用户 RBAC 矩阵内。
> 接口级鉴权点见 `03-接口设计.md`;答案黑盒与判题隔离要求见 `06-安全设计.md`。
