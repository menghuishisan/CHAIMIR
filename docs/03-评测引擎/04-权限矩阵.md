# 评测引擎 权限矩阵

> 最后更新:2026-11-27

本模块复用 M1 的用户角色与租户身份，角色基线见[身份权限矩阵](../01-身份与租户/04-权限矩阵.md)。本表定义本模块资源范围；角色本身不授予资源拥有权，具体操作仍须通过接口的归属与授权校验。

| 角色 | 本模块数据范围 | 本模块操作权限 |
| --- | --- | --- |
| 学生(student) | 由 M6/M7/M8 授权的本人作答与结果 | 经所属业务提交和读取，不直接调用 M3 用户 HTTP 端点 |
| 教师(teacher) | 本人拥有来源或本人提交的判题任务 | 查看、订阅进度、人工评分和单条重判；只读判题方式目录 |
| 校管(school_admin) | 与教师相同的来源归属范围 | 操作同教师，不因校管角色读取全校他人任务 |
| 平台管理员(platform_admin) | 平台级判题器及目录 | 登记、编辑、自检判题器；不直接进入租户任务接口 |

> 引擎内部的判题调度 worker、judge 沙箱执行器等自动化组件以平台服务身份运行,不属于上述用户角色,其权限由架构设计与 `06-安全设计.md` 约束,不在此用户 RBAC 矩阵内。
> 接口级鉴权点见 `03-接口设计.md`;答案黑盒与判题隔离要求见 `06-安全设计.md`。
