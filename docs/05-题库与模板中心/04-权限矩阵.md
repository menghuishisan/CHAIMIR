# 题库与模板中心 权限矩阵

> 最后更新:2026-08-25

本模块无独立于身份(identity)模块的用户权限扩展。所有用户角色、数据范围与操作权限继承 `docs/01-身份与租户/04-权限矩阵.md` 的租户 RBAC 定义;本模块接口仅按角色开放对应操作,不新增用户角色或数据范围维度。

| 角色 | 本模块数据范围 | 本模块操作权限 |
| --- | --- | --- |
| 学生(student) | 公开/本人可见的题目与模板 | 浏览、引用为作业/题目 |
| 教师(teacher) | 本人创建/任教的题目与模板 | 增删改查本人题目与模板、发布 |
| 校管(school_admin) | 本校租户内全部题目与模板 | 本校题目审核、共享管理 |
| 平台管理员(platform_admin) | 跨租户(平台维度) | 平台级题库治理 |

> 接口级鉴权点见 `03-接口设计.md`;题目/模板的可见范围与答案黑盒要求见 `06-安全设计.md`。
