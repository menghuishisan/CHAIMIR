# 题库与模板中心 权限矩阵

> 最后更新:2026-11-27

本模块复用 M1 的用户角色与租户身份，角色基线见[身份权限矩阵](../01-身份与租户/04-权限矩阵.md)。本表定义本模块资源范围；角色本身不授予资源拥有权，具体操作仍须通过接口的归属与授权校验。

| 角色 | 本模块数据范围 | 本模块操作权限 |
| --- | --- | --- |
| 学生(student) | M6/M7/M8 已授权业务中的题面 | 经所属业务读取题面,不直接检索或管理题库 |
| 教师(teacher) | 本人内容、本校公开题面及已发布共享题面 | 管理本人内容、发布/共享、按可见范围克隆与组卷;全量仅本人内容 |
| 校管(school_admin) | 本人内容、本校公开题面及已发布共享题面 | 按作者归属管理内容、按可见范围克隆与组卷;无全量接口或他人内容审核特权 |
| 平台管理员(platform_admin) | 无直接题库入口 | 不提供跨校题库治理接口 |

分类在当前租户内维护;试卷重新抽题校验试卷作者。内部服务按服务身份和租户契约读取锁定内容,不借用管理员身份。

> 接口级鉴权点见 `03-接口设计.md`;题目/模板的可见范围与答案黑盒要求见 `06-安全设计.md`。
