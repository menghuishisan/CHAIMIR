## 4. 高频跨页面系统性缺陷(按类批量修,不逐页修)

1. **内部标识直出用户界面(FE-4 最大违规面)**:审计页 `auth.login`/`actor_id`、通知 `assignment.published` 与公告 scope 枚举数字、成绩/名册/监控以雪花 ID 作主列(24+ 处)、状态列直出枚举数字(result/replay/anti-cheat/ContentItemActions 等 8 处)、ISO 时间未格式化。已有 labels 映射(如 `sandboxStatusLabel` 8 态、`vulnLevelLabel`、`announcementScopeLabel`)存在但未调用。
2. **要求用户手输内部 ID**:批改中心(作业/课程/提交)、成绩报送、名册添加学生、申诉、检查点判分、队伍/对局编号、反作弊竞赛/题目 UUID 等 14+ 处,多个页面因此实际不可用。
3. **裸 JSON 文本域交给用户**:16+ 处(题目正文、课时内容引用、成绩映射、告警条件、平台配置、实验组件/协作、竞赛规则/动态分/对抗、复核依据、功能开关、漏洞源配置等)。
4. **表单基线缺失**:placeholder-only 零 label 输入 50+(runtimes/sandbox-tools/judges 三页最重);裸 label 无 htmlFor 145+;blur 校验全站 0;必填标记大面积缺失;静默 return 不提示 10+ 处;约半数写操作按钮无 loading(可重复提交)。
5. **三态与反馈**:骨架屏 0(87 页 Spinner);空态引导按钮 0;页内错误仅 34% 带 `role="alert"`;成功/失败共用灰色 message 样式多处;`ErrorState.onRetry` 被滥用为「关闭提示」。
6. **危险操作**:与常规操作同排无分离、无确认或用 `window.confirm`(9+ 处);校管账号行 5 操作含「注销」相邻排列。
7. **§6.5 页面范式 0 落地**:kicker 面包屑(硬编码 div 20 页,组件 0 用)、指标带 8/90(auto-fit 仅 2)、主区+动作区双栏 8/90、动作卡范式 0、看板/统计零图表(30 天时序渲染为文字表)。
8. **布局与海拔**:19 个 feature CSS 仅 1 处 box-shadow,灰底灰卡无层次;内容区锁 1200px 单列无宽幅变体;嵌套滚动容器破坏滚动位置恢复;`MainLayout` 底色用 `--color-surface` 与卡片同色抹平海拔。
9. **列表能力**:全部硬编码 `page:1,size:20`(部分 100),无分页控件,超量数据永久不可达;搜索无防抖逐字符请求;虚拟滚动 0。
10. **多步骤持久化(FE-7)**:6 个向导仅作业草稿 1 个真正落服务端;`Steps`/`Autosave` 零使用;实验编排把 `wizard_step` 做成手填数字输入框。
11. **无障碍**:密码框显隐切换 0/11;移动端认证页无 h1;skip-link 缺失;tablist 结构错误;焦点管理缺失;`Select` 无可访问名称(label 包裹 button 无效)。
12. **规范级空缺(§7/§9.1 创新点)**:①区块孵化器 0 态(非简陋两态);②时空回溯器不存在(replay 页无拓扑/日志流/时间轴,浅色页错挂深色壳);③IDE WS 进度内容被丢弃仅触发 reload;④审核页看不到扫描报告详情即要求通过/退回。

## 5. 分端 P0 索引(逐页明细见各批次审查输出)

- **公共认证(8 页)**:无 P0,但全线无 blur 校验、无密码显隐、错误不就近;forgot 页要求输入后端数字主键「学校编号」;三个公共页脱离 AuthLayout 品牌壳。
- **学生端**:课时页渲染 content_ref 原始 JSON + 枚举数字;成绩页 course_id 作主列;成绩动作区样式类缺失;实验/竞赛工作台见 S7/S8/D 系列;replay 功能级空缺。
