# 成绩中心 权限矩阵

> 最后更新:2026-11-27

本模块复用 M1 的用户角色与租户身份，角色基线见[身份权限矩阵](../01-身份与租户/04-权限矩阵.md)。本表定义本模块资源范围；角色本身不授予资源拥有权，具体操作仍须通过接口的归属与授权校验。

| 角色 | 本模块数据范围 | 本模块操作权限 |
| --- | --- | --- |
| 学生(student) | 本人已发布学业记录 | 读取本租户等级映射/学期，查看本人已发布成绩/GPA、申诉、确认预警、生成成绩单 |
| 教师(teacher) | 本人任教课程的审核与申诉 | 读取本租户等级映射/学期、本人报送审核，报送课程审核、处理申诉；课程成绩通过 M6 查看，不读取 M11 学生整体记录 |
| 校管(school_admin) | 本校租户内全部成绩 | 本校成绩审核与导出 |
| 平台管理员(platform_admin) | 无租户成绩读取范围 | 不开放学生学业记录 |

> 成绩归属与发布流程见 `05-业务流程与状态机.md`;接口级鉴权点见 `03-接口设计.md`;成绩数据隔离要求见 `06-安全设计.md`。
