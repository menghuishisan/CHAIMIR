# 成绩中心 权限矩阵

> 最后更新:2026-08-25

本模块无独立于身份(identity)模块的用户权限扩展。所有用户角色、数据范围与操作权限继承 `docs/01-身份与租户/04-权限矩阵.md` 的租户 RBAC 定义;本模块接口仅按角色开放对应操作,不新增用户角色或数据范围维度。

| 角色 | 本模块数据范围 | 本模块操作权限 |
| --- | --- | --- |
| 学生(student) | 本人成绩记录 | 查看本人成绩与排行 |
| 教师(teacher) | 本人任教范围的成缋 | 录入/复核任教范围成绩、发布 |
| 校管(school_admin) | 本校租户内全部成绩 | 本校成绩审核与导出 |
| 平台管理员(platform_admin) | 跨租户(平台维度) | 平台级成绩治理 |

> 成绩归属与发布流程见 `05-业务流程与状态机.md`;接口级鉴权点见 `03-接口设计.md`;成绩数据隔离要求见 `06-安全设计.md`。
