# 管理后台 权限矩阵

> 最后更新:2026-08-25

本模块无独立于身份(identity)模块的用户权限扩展。所有用户角色、数据范围与操作权限继承 `docs/01-身份与租户/04-权限矩阵.md` 的租户 RBAC 定义;本模块接口仅按角色开放对应操作,不新增用户角色或数据范围维度。

| 角色 | 本模块数据范围 | 本模块操作权限 |
| --- | --- | --- |
| 学生(student) | 无管理后台操作权限 | — |
| 教师(teacher) | 本人任教相关的管理视图 | 查看本人教学/实验/竞赛管理数据 |
| 校管(school_admin) | 本校租户内全部管理数据 | 本校租户配置、用户与资源治理 |
| 平台管理员(platform_admin) | 跨租户(平台维度) | 平台级租户、配置与运营治理 |

> 管理后台为聚合只读/治理层,不跨写业务模块数据,详见 `05-业务流程与状态机.md`;接口级鉴权点见 `03-接口设计.md`。
