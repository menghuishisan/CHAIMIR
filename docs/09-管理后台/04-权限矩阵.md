# 管理后台 权限矩阵

> 最后更新:2026-11-27

本模块复用 M1 的用户角色与租户身份，角色基线见[身份权限矩阵](../01-身份与租户/04-权限矩阵.md)。本表定义本模块资源范围；角色本身不授予资源拥有权，具体操作仍须通过接口的归属与授权校验。

| 角色 | 本模块数据范围 | 本模块操作权限 |
| --- | --- | --- |
| 学生(student) | 无管理后台操作权限 | — |
| 教师(teacher) | 无 M9 权限 | 在 M6/M7/M8 管理本人业务 |
| 校管(school_admin) | 本校租户内全部管理数据 | 本校运营、审计、告警；用户与学校设置归 M1 |
| 平台管理员(platform_admin) | 跨租户(平台维度) | 跨校运营、审计、告警与监控；租户治理归 M1 |

> 管理后台为聚合只读/治理层,不跨写业务模块数据,详见 `05-业务流程与状态机.md`;接口级鉴权点见 `03-接口设计.md`。
