# 沙箱引擎 权限矩阵

> 最后更新:2026-08-25

本模块无独立于身份(identity)模块的用户权限扩展。所有用户角色、数据范围与操作权限继承 `docs/01-身份与租户/04-权限矩阵.md` 的租户 RBAC 定义;本模块接口仅按角色开放对应操作,不新增用户角色或数据范围维度。

| 角色 | 本模块数据范围 | 本模块操作权限 |
| --- | --- | --- |
| 学生(student) | 本人/本队所属的沙箱与环境 | 进入本人沙箱、提交代码、查看本人运行结果 |
| 教师(teacher) | 本人创建/任教的实验与题目所属沙箱 | 编排沙箱、发布组合快照、查看任教范围数据 |
| 校管(school_admin) | 本校租户内全部沙箱与镜像 | 本校镜像审核、回收策略管理 |
| 平台管理员(platform_admin) | 跨租户(平台维度) | 平台级镜像/沙箱治理 |

> 引擎内部的编排器、预拉取 DaemonSet、回收器等自动化组件以平台服务身份运行,不属于上述用户角色,其权限由架构设计(`07-架构设计.md`)与 `06-安全设计.md` 约束,不在此用户 RBAC 矩阵内。
> 接口级鉴权点见 `03-接口设计.md`;不可信隔离与多租户隔离要求见 `06-安全设计.md`。
