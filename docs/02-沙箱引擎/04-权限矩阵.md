# 沙箱引擎 权限矩阵

> 最后更新:2026-11-27

本模块复用 M1 的用户角色与租户身份，角色基线见[身份权限矩阵](../01-身份与租户/04-权限矩阵.md)。本表定义本模块资源范围；角色本身不授予资源拥有权，具体操作仍须通过接口的归属与授权校验。

| 角色 | 本模块数据范围 | 本模块操作权限 |
| --- | --- | --- |
| 学生(student) | 本人拥有、显式共享或有效竞赛 grant 授权的环境 | 按资源访问类型使用工作区、工具与链能力；不能进入私有判题或对局沙箱 |
| 教师(teacher) | 本人拥有或显式授权的环境及可用组件目录 | 通过业务模块编排组合；工作区操作仍校验沙箱授权 |
| 校管(school_admin) | 本校配额、用量及本人获得授权的环境 | 读取本校配额与用量；不因校管身份取得他人工作区权限 |
| 平台管理员(platform_admin) | 全局运行时、工具、镜像目录及租户配额 | 登记、预拉取、自检、停用目录资源和配置配额；不进入租户工作区 |

> 引擎内部的编排器、预拉取 DaemonSet、回收器等自动化组件以平台服务身份运行,不属于上述用户角色,其权限由架构设计(`07-架构设计.md`)与 `06-安全设计.md` 约束,不在此用户 RBAC 矩阵内。
> 接口级鉴权点见 `03-接口设计.md`;不可信隔离与多租户隔离要求见 `06-安全设计.md`。
