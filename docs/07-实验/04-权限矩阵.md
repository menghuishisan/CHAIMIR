# 实验 权限矩阵

> 最后更新:2026-11-27

本模块复用 M1 的用户角色与租户身份，角色基线见[身份权限矩阵](../01-身份与租户/04-权限矩阵.md)。本表定义本模块资源范围；角色本身不授予资源拥有权，具体操作仍须通过接口的归属与授权校验。

| 角色 | 本模块数据范围 | 本模块操作权限 |
| --- | --- | --- |
| 学生(student) | 本人/本队参与的实验与环境 | 进入实验、操作沙箱、提交报告 |
| 教师(teacher) | 本人发布/任教的实验 | 编排组合、发布快照、查看任教范围数据 |
| 校管(school_admin) | 本校租户内全部实验 | 本租户实验定义、分组、报告及实例监控管理；学生工作台仍须实例归属/当前成员授权 |
| 平台管理员(platform_admin) | 无本模块用户入口 | 不直接读取或治理租户实验；内部接口使用服务签名身份 |

> 多人/小组实验的成员权限变更由小组行锁串行处理,详见 `05-业务流程与状态机.md`;接口级鉴权点见 `03-接口设计.md`。
