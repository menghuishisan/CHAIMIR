# 实验 权限矩阵

> 最后更新:2026-08-25

本模块无独立于身份(identity)模块的用户权限扩展。所有用户角色、数据范围与操作权限继承 `docs/01-身份与租户/04-权限矩阵.md` 的租户 RBAC 定义;本模块接口仅按角色开放对应操作,不新增用户角色或数据范围维度。

| 角色 | 本模块数据范围 | 本模块操作权限 |
| --- | --- | --- |
| 学生(student) | 本人/本队参与的实验与环境 | 进入实验、操作沙箱、提交报告 |
| 教师(teacher) | 本人发布/任教的实验 | 编排组合、发布快照、查看任教范围数据 |
| 校管(school_admin) | 本校租户内全部实验 | 本校实验审核、资源管理 |
| 平台管理员(platform_admin) | 跨租户(平台维度) | 平台级实验治理 |

> 多人/小组实验的成员权限变更由小组行锁串行处理,详见 `05-业务流程与状态机.md`;接口级鉴权点见 `03-接口设计.md`。
