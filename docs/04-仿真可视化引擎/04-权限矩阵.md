# 仿真可视化引擎 权限矩阵

> 最后更新:2026-08-25

本模块无独立于身份(identity)模块的用户权限扩展。所有用户角色、数据范围与操作权限继承 `docs/01-身份与租户/04-权限矩阵.md` 的租户 RBAC 定义;本模块接口仅按角色开放对应操作,不新增用户角色或数据范围维度。

| 角色 | 本模块数据范围 | 本模块操作权限 |
| --- | --- | --- |
| 学生(student) | 本人创建的仿真会话与提交包 | 运行仿真、查看本人会话帧与检查点 |
| 教师(teacher) | 本人上架的仿真包与任教的仿真实验 | 上架/下架仿真包、查看任教范围数据 |
| 校管(school_admin) | 本校租户内全部仿真包与会话 | 本校仿真包审核 |
| 平台管理员(platform_admin) | 跨租户(平台维度) | 平台级仿真治理 |

> 引擎内部的仿真隔离运行器、stdio 适配器、审核双跑环境等自动化组件以平台服务身份运行,不属于上述用户角色,其权限由 `07-架构设计.md` 与 `06-安全设计.md` 约束,不在此用户 RBAC 矩阵内。
> 接口级鉴权点见 `03-接口设计.md`;不可信代码隔离要求见 `06-安全设计.md`。
