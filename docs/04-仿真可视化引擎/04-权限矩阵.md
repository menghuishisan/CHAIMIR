# 仿真可视化引擎 权限矩阵

> 最后更新:2026-11-23

本模块无独立于身份(identity)模块的用户权限扩展。所有用户角色、数据范围与操作权限继承 `docs/01-身份与租户/04-权限矩阵.md` 的租户 RBAC 定义;本模块接口仅按角色开放对应操作,不新增用户角色或数据范围维度。

| 角色 | 本模块数据范围 | 本模块操作权限 |
| --- | --- | --- |
| 学生(student) | 已发布包；本人拥有或已获共享授权的会话 | 查看场景、继续可用会话、读取归档回放；可用会话可创建公开分享 |
| 教师(teacher) | 已发布包、本人提交包；本人拥有或已获共享授权的会话 | 提交扩展包、修改草稿或已退回包、查看本人预览报告；会话操作同学生 |
| 校管(school_admin) | 已发布包、本人提交包；本人拥有或已获共享授权的会话 | 扩展包提交及会话操作同教师；不审核或上下架平台级包 |
| 平台管理员(platform_admin) | 平台级仿真包与审核记录 | 审核通过或退回、下架及重新上架；不借平台身份进入租户会话 |

匿名入口仅按有效分享码读取脱敏剧本；公开页仅执行内置包，不创建隔离环境。业务服务使用签名身份及稳定 `source_ref` 创建、归档和回收所属会话；终端角色不能直接调用内部生命周期入口。M7 的任教范围和 M8 的赛事权限由来源模块负责，M4 按持久化会话授权及来源模块开关限制执行与回放。

> 引擎内部的仿真隔离运行器、stdio 适配器、审核双跑环境等自动化组件以平台服务身份运行,不属于上述用户角色,其权限由 `07-架构设计.md` 与 `06-安全设计.md` 约束,不在此用户 RBAC 矩阵内。
> 接口级鉴权点见 `03-接口设计.md`;不可信代码隔离要求见 `06-安全设计.md`。
