# M6 教学 — 安全设计

> 教学涉及作业答案、学生成绩、课程成员边界。本文覆盖成员鉴权、答案防泄露、成绩防篡改、越权防护。
> 最后更新:2026-08-05

---

## 1. 课程成员与访问鉴权

- 课程内容、作业、讨论仅对**课程成员**(已加入学生 + 授课教师)可见。
- 学生只能访问自己加入的课程;非成员访问返回无权限。
- 教师只能管理自己负责的课程;跨课程操作校验归属。
- 回复创建必须在课程成员鉴权后校验父帖的租户、课程与未删除状态,并在事务内锁定父帖避免校验后被并发删除。回复引用只按同租户、同课程的可见父帖投影正文;被删除父帖不得通过引用重新呈现。
- 邀请码:有限长度 + 可刷新;失效/课程结束后不可加入。

---

## 2. 作业答案防泄露

- 学生取作业题面经 M5 题面接口(已过滤 answer/judge_config/flag),M6 不缓存答案。
- 客观理论题由 M3 J7 后端策略判分,不创建代码判题容器;M6 只提交学生答案并接收得分,不读取标准答案。
- 学生提交未截止前,不可查看他人提交;成绩公布前不可见参考答案(教师可配公布时机)。

---

## 3. 成绩防篡改与可追溯

- 成绩计算与调整仅授课教师可操作;手动调整保留 auto_total + 标记 is_overridden,可追溯。
- 作业权重来源必须在保存和计算事务内验证同租户、同课程及未删除状态;跨课程编号不能用于读取提交或汇总。计算前完整校验已保存权重,缺失或无效时整次拒绝,不覆盖既有成绩。
- 学生不可改任何成绩字段(只读自己成绩)。
- 成绩相关操作记审计(谁、何时、改了谁、原值→新值)。
- M11 对成绩只读聚合,无写权限。

---

## 4. 提交与防作弊(协作 M3)

- 提交次数受 max_attempts 限制;截止后按迟交策略,不允许时拒收。
- 草稿不计入提交次数、不触发判分。

---

## 5. 越权与多租户

- 所有教学数据 `tenant_id` + RLS;跨租户不可见。
- 课程克隆：本人课程可克隆；他人课程仅在已发布且 `visibility=共享` 时可克隆。副本不带成员、提交或成绩。外校来源仅在受控 M6 事务内读取和复制材料；来源事务结束后，由目标学校的普通租户事务统一保存课程、题目引用和 M1 审计。不得在特权来源事务中写目标业务，也不得让特权事务借给其他模块。
- 共享目录的章节数:`chapter` 的行级安全只开放本校,目录预览要显示「共 n 章」时,M6 在受控特权事务(与跨校克隆同一入口 `PrivilegedTx`)里按当前页课程编号一次计数。查询本身再次限定课程**此刻仍是共享、非草稿、未删除且不属于本校**,只返回每门课的章节**数量**,不返回章节标题、课时或任何学生数据;课程取消共享后立即读不到。
- 接口层校验:学生改进度/提交只能针对本人;教师操作限本课程。

---

## 6. 内容与存储安全

- 视频/附件/报告存对象存储,按 tenant/course 路径隔离,下载经鉴权(防直链盗取)。
- 课程克隆、封面保存和课时材料上传失败时，仅补偿本次新对象。提交结果不明时保留对象，不能因事后查询未命中就删除；尚未尝试提交时才清理。请求取消不取消补偿，错误链保留原操作与清理失败；响应转换在提交前完成。
- 依赖复制契约仅由已授权并锁定来源课程的 M6 内部调用。M5、M7 用来源租户普通事务只读取自有表，不暴露隐藏内容；返回的新引用不可用用户参数替换。M7 校验实验归属来源课程，未绑定课程的课时实验另须属于来源教师；M2 校验输入等于已登记冻结快照，素材只允许来源租户代码/附件或快照内已有的平台素材。保存必须复用目标普通事务，失败补偿覆盖本次全部依赖对象；不放宽 RLS 或普通跨校读取。
- 封面暂存引用绑定租户、上传教师和上传编号；正式对象绑定课程和独立编号，路径与统一文件授权的课程前缀一致。替换须锁定课程并校验读取后封面未变化，业务与审计同事务；失败仅补偿本次目标对象，保留原封面和暂存源。临时标签由桶生命周期清理，正式复制不得继承该标签。
- 富文本/讨论内容的 XSS 防护在**渲染层**:正文按原文入库(不做 HTML 实体转义),前端一律经 React 文本节点渲染,全站零 `dangerouslySetInnerHTML`,叠加前端服务下发的 CSP(`script-src 'self'`,见 `images/service/frontend/security-headers.conf`)。存储层转义是错的:后端不产出 HTML,转义只会把学生看到的 `a < b` 变成 `a &lt; b`,而区块链课程的正文与讨论必然出现代码片段与比较符号;课时正文还可被反复编辑,每次编辑都会再转义一层。
- 课时关联的实验/仿真执行安全由 M2/M4 保证,M6 只存引用。

---

## 7. 安全测试要点

- 非成员访问课程内容/作业被拒。
- 学生无法获取作业答案、无法查看他人未公布提交。
- 学生无法篡改成绩/进度/他人数据。
- 跨租户访问课程数据被 RLS 拦截。
- 附件直链未鉴权访问被拒;讨论区脚本注入在渲染层被文本节点与 CSP 阻断,且正文原文不被转义走形。
