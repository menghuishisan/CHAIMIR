# 教学 权限矩阵

> 最后更新:2026-11-27

本模块复用 M1 的用户角色与租户身份，角色基线见[身份权限矩阵](../01-身份与租户/04-权限矩阵.md)。本表定义本模块资源范围；角色本身不授予资源拥有权，具体操作仍须通过接口的归属与授权校验。

| 角色 | 本模块数据范围 | 本模块操作权限 |
| --- | --- | --- |
| 学生(student) | 本人选修的课程与学习记录 | 学习、提交作业、查看本人成绩 |
| 教师(teacher) | 本人任教/创建的课程与班级 | 课程与章节管理、布置作业、批改 |
| 校管(school_admin) | 本人负责或作为成员加入的课程、受限共享目录 | 依课程负责人或成员身份使用对应入口；全校运营聚合见 M9、成绩审核见 M11 |
| 平台管理员(platform_admin) | 无租户课程操作范围 | 不开放 M6 课程内容、成员、作业或成绩入口 |

> 接口级鉴权点见 `03-接口设计.md`;学习数据隔离要求见 `06-安全设计.md`。
