# runtime/evm-hardhat

提供 Hardhat Solidity 开发工具和 Anvil EVM 链。固定工具与编译器版本、端口、启动参数和供应链约束以 manifest 与 Dockerfile 为准，不在运行时下载编译器。

原生适配器接受一份 JSON 对象：`deploy` 发送字节码；`tx` 接受目标、调用数据、可选金额和节点解锁账户，未指定账户时读取节点首个可用账户；无账户则失败。`query` 支持链编号、最新区块、账户余额和合约字节码，其他目标拒绝。

教学钱包签名使用独立载荷 `{"raw_transaction":"0x..."}`，须为非空完整十六进制字节且不混入其他字段。适配器原样广播、不重新签名；复用 `cast publish` 与系统 `timeout`。普通发送使用 Cast 的超时，两者时限均来自正整数 `FOUNDRY_TRANSACTION_TIMEOUT`。

交易须取得成功回执与合法交易哈希，部署还须有非零合约地址后才更新最近部署引用。错误输入在执行前拒绝，失败不会改用平台账户重发。工作区可在组合内共享，账本由 M2 按链独立管理；主容器不开放学生 shell。

验收先执行 manifest 中的工具、广播入口、限时工具与编译器自检，再验证实际部署、调用、钱包广播、错误回执、查询、持久化和清理。版本自检与本地进程替身不能代替真实链和组合验收。
