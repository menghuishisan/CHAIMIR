## 镜像职责

链上事件监听教学服务镜像。
内部请求 HMAC 使用完整 64 位十六进制签名和 16–128 位字母、数字、下划线或连字符 nonce。`CHAIMIR_IMAGE_SERVICE_AUTH_MAX_NONCES` 限制当前进程尚未过期的防重放记录；满额返回 503，不驱逐有效记录。
采集逐轮执行，游标和事件先原子落盘、再更新可见状态。链高度回退后按回查范围重建；重组重放指定深度，并检查保留事件仍属于当前链。整轮采集以同一已确认末块校验链稳定性；末块变化、区块缺失或更深的旧事件已失效时，本轮失败且不推进游标。健康检查和最新事件接口在采集异常时返回 503；状态文件只允许规范化的私有运行域路径。
