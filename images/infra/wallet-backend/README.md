## 镜像职责

DApp 登录和签名教学钱包后端镜像。
`/challenge` 生成绑定白名单域名和钱包地址的一次性消息，`/verify` 校验外部钱包签名；挑战和内部请求 nonce 保存于私有状态卷。内部请求 HMAC 使用 64 位十六进制签名和 16–128 位字母、数字、下划线或连字符 nonce。`CHAIMIR_IMAGE_SERVICE_AUTH_MAX_NONCES` 限制尚未过期的防重放记录；满额返回 503，不驱逐有效记录。单次状态写入失败向调用方报告，后续保存可恢复；写入与临时文件清理同时失败时保留两个原因。
