# tool/db-viewer

> 更新：2026-11-27。机器字段以本目录 [manifest](manifest.yaml) 为准；构建、供应链、通用隔离和验收遵循[镜像规范](../../../docs/总-镜像与容器设计.md)。

## 镜像职责

状态数据库可视化工具镜像。

## bindings 与 links

- 数据库绑定只接收 `主机:端口`，端口范围 1–65535；入口拒绝内嵌协议、凭据、路径、查询和片段。

## Secret / KMS

- 数据库密码由标准库转义，完整保留空白与特殊字符，不在错误中回显。
- 数据库连接要求 TLS，连接 URL 与 pgweb 启动选项使用同一加密要求。
