# tool/slither

通过固定入口 `chaimir-slither`，使用 Slither 0.11.3 对共享工作区执行 Solidity 静态分析。

- 组合必须显式选择 `SOLIDITY_VERSION`：0.8.20、0.8.24 或 0.8.26。入口核对镜像内的对应编译器，再把固定 `--solc` 路径交给 Slither。
- 扫描目标为 `/workspace`，JSON 报告写入标准输出，诊断写入标准错误，保留分析器退出码。无源码、缺少版本或编译器不匹配时明确失败。
- 工具与链运行时共享工作区，无 RPC、HTTP 端口或 provider 连接；默认禁止网络。挂载、资源限制和最大执行时间由 manifest 与 M2 统一控制。

验收须先通过 manifest 的命令和编译器自检，再对真实工作区验证正常合约、漏洞发现、编译失败和多文件分析。版本自检不能代替静态分析验收。
