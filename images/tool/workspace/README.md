# tool/workspace

> 更新：2026-11-27。机器字段以本目录 [manifest](manifest.yaml) 为准；构建、供应链、通用隔离和验收遵循[镜像规范](../../../docs/总-镜像与容器设计.md)。

## 镜像职责

工作区脚本与 Dockerfile 同目录维护，构建上下文只包含本镜像源码；不从通用工具基座目录复制业务入口。
工作区文件、归档和受控终端能力。平台也复用同一镜像在独立非学生 `init-script` 容器执行教师初始化脚本,容器标签、私有临时卷和执行目标必须独立声明。

## command / args 语义

- `run <workspace> <workdir>` 只从 stdin 接收原始脚本,在非学生容器的私有 `/tmp` 中执行并清理;不接受脚本文件路径,不得在学生入口调用。文件、终端、归档入口清除根 `.chaimir-init-script` 私有保留条目,保留其他工作区数据。
- `clean <workspace>` 供首次启动、暂停/快照恢复和平台自检在非学生容器中显式清理精确根副本;失败时不得开放工作台。
