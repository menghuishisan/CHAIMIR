# tool/mythril

通过固定入口 `chaimir-mythril`，使用 Mythril 0.24.8 逐个分析共享工作区中的 Solidity 文件。

- 组合必须显式选择 `SOLIDITY_VERSION`：0.8.20、0.8.24 或 0.8.26。编译器随镜像提供，经 py-solc-x 使用，不在运行时下载。
- 输出 JSON 包含选定版本和每个源文件的原始报告、退出码。所有文件分析成功时顶层 `success=true`；漏洞保留在 `issues`，不等同于分析失败。编译错误、异常退出或无效报告使顶层失败并返回非零退出码。
- 无源码、版本缺失或编译器不匹配时明确失败。输入来自 `/workspace`，命令不提供任意参数入口。
- 工具与链运行时共享工作区，无 RPC、HTTP 端口或 provider 连接；默认禁止网络。挂载、资源限制和最大执行时间由 manifest 与 M2 统一控制。

验收须先通过 manifest 的编译器和命令自检，再对真实工作区验证正常合约、漏洞合约、编译失败、多文件结果及资源回收。版本自检不能代替符号执行验收。
