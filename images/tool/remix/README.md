# tool/remix

服务固定上游镜像中的 Remix Web IDE 静态资源；不自行实现编译器、账户管理或链部署。

入口 remix-static-server 接收 -addr 和 -root，HTTP 超时由 CHAIMIR_HTTP_TIMEOUT_SECONDS 配置。服务以 os.Root 限制资源根目录，使用标准 HTTP 内容服务处理 MIME、HEAD、范围及条件请求。仅不存在的无扩展名 HTML 导航回退 index.html；缺失资源返回 404，目录外符号链接不可读取。

镜像不挂载学生工作区或临时写卷，不包含 nginx 执行入口。IDE 内的浏览器文件不会自动同步平台工作区；可用的编译器和插件取决于固定上游包及受控网络，不能以静态页面可访问证明离线编译或链部署可用。

镜像版本、启动参数、端口、资源和隔离以 manifest.yaml 为准。容器非 root、根文件系统只读、网络默认拒绝。

验收须在工具代理中打开真实页面，加载资源并完成实际 Solidity 编译，再验证所选链的真实部署与调用（若使用）；静态处理器测试和版本自检只覆盖各自范围。
