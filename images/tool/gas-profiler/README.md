# tool/gas-profiler

固定命令 `gas-profiler` 从标准输入读取交易回执，输出数量、总 Gas、最小值、最大值和均值。

- 输入为回执数组或 `{ "receipts": [...] }`。每项必须有 `gasUsed`，接受标准 RPC 十六进制数量及 SDK 的非负整数、十进制字符串。
- 缺失字段或非法值使命令非零退出，不输出部分统计；空数组输出零统计。
- 工具不请求节点、不广播交易、无监听端口；回执由工作台或调用方提供。挂载、资源与隔离由 manifest 和 M2 管理，默认禁止网络。

验收先执行 manifest 的回执自检，再验证真实链回执、混合合法与非法输入、空输入和大批量数据。样例统计不能代替真实链联动与性能验收。
