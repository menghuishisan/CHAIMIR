# @chaimir/sim-sdk

> 更新：2026-11-27。

平台仿真协议、确定性工具、包创作模板与浏览器运行时客户端。公开导出以 [src/index.ts](src/index.ts) 为准，完整协议和可执行创作示例统一维护在[M4 SDK 与交互协议](../../../docs/04-仿真可视化引擎/08-可视化SDK与交互协议.md)，本入口不复制第二份示例。

平台内置包在受限 Web Worker 中装配，目录由 SDK 内置 registry 管理。教师与第三方扩展包统一在后端隔离容器执行，浏览器只消费纯数据教学帧；扩展包不得自行选择浏览器执行。隔离要求见[M4 安全设计](../../../docs/04-仿真可视化引擎/06-安全设计.md)。

浏览器主入口不导出内置算法 registry 或 Node 容器宿主。容器入口由 [package-runner](../../../images/sim/package-runner/README.md) 的构建链生成；共享计算引擎和类型协议在 SDK 内维护。
